# Implementation plans

These are the implementation briefs as they were issued to the agents that did the work,
kept as written so that the specification of each experiment stays checkable against its
result. The unticked checkboxes are the state of the brief at the moment it was written,
not outstanding work. Every experiment described here has been run, and its numbers are in
the tracked snapshot under `results/`, with the write-up in each `experiments/NN_*/README.md`.
Read these files as a record of how the work was specified, not as a to-do list.
