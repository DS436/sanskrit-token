## Task 4: Intrinsic metrics: fertility, compression, parity

Goal: three pure metric modules with unit tests against hand-computed examples.

Spec:
- `src/sanskrit_tok/tokenizers/base.py`: `class Tokenizer(Protocol): name: str; def encode(self, text: str) -> list[int]: ...`. Also a `MetricResult = dict[str, Any]` alias is acceptable but prefer a `TypedDict` `MetricResult` with required keys `value: float`, `n: int`, `unit: str` and `total=False` extras.
- `metrics/fertility.py`: `fertility(tokenizer, texts) -> MetricResult`. Words are whitespace-delimited (`str.split()`). Each word is encoded independently. `value` = total tokens / total words, `n` = total words, `unit = "tokens/word"`, plus `per_word: list[int]` (token count per word, in order). Empty input → `value 0.0, n 0`.
- `metrics/compression.py`: `compression(tokenizer, texts) -> MetricResult`. Each text encoded whole. `value` = total UTF-8 bytes of the texts / total tokens, `n` = total tokens, `unit = "bytes/token"`, plus `per_text: list[float]`. Caller passes SLP1 or original-script texts; the function does not transliterate. Docstring must say to report both.
- `metrics/parity.py`: `parity(tokenizer, texts, pivot_texts, pivot_tokenizer=None) -> MetricResult`. `texts[i]` aligned with `pivot_texts[i]`; assert equal length. `value` = sum(tokens(texts)) / sum(tokens(pivot_texts)) with `pivot_tokenizer` defaulting to `tokenizer`. `n` = number of pairs, `unit = "token ratio"`, plus `per_pair: list[float]`. Docstring cites Petrov et al. 2023.
- `tests/test_metrics.py`: a `CharTokenizer` (one token per character) and a `WordTokenizer` (one token per whitespace word) as fakes. Hand-computed cases: fertility of `["ab cde"]` under `CharTokenizer` is 5/2 = 2.5 with `per_word [2, 3]`; compression of `["ab cde"]` under `CharTokenizer` is 6 bytes / 6 tokens = 1.0, and of `["āb"]` is 3 bytes / 2 tokens = 1.5; parity of `["abc"]` vs `["ab"]` under `CharTokenizer` is 1.5; parity with different tokenizers on each side; length mismatch raises `ValueError`; empty input handling.
- TDD required. Lint, types, tests clean. Commit `metric: add fertility, compression, parity with tests`.
