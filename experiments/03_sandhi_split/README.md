# Experiment 03 — Sandhi splitting before subword learning (RQ3)

**Hypothesis:** reversing sandhi before subword training (the T4 arms) recovers token
efficiency relative to the matched raw-text T1/T2 baselines.

**Success:** T4 arms at matched 32k/64k vocabularies beat T1/T2 on TPP and MorphScore.
