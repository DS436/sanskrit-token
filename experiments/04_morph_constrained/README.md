# Experiment 04 — Morpheme-constrained merges (RQ4)

**Hypothesis:** forbidding BPE merges across gold morpheme boundaries (T5 on raw text,
T6 on sandhi-split text) improves morphological alignment without costing compression.

**Success:** T6 is the best arm on MorphScore and no worse than T4 on TPP.
